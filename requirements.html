Examples for the oral exam

  1. Training data: How could a model’s training data affect its market analysis?
    Answer

    Training data describes past conditions. Market changes after training require fresh information.

  2. Training versus inference: Does uploading a company report change the model’s weights?
    Answer

    No. Uploading a report adds context for the response. Training updates the model’s weights.

  3. Base models versus assistants: Why might a base model continue a customer’s question instead of answering it?
    Answer

    A base model learns to continue documents. Assistant post-training teaches it to respond to instructions and questions.

  4. Hallucinations: Why might a model confidently invent a supplier’s history or a source for a business claim?
    Answer

    The model learns to imitate human-written answers. Hallucinations occur when it fills a familiar answer pattern with invented details. Predicting likely text does not verify facts.

  5. Context and tools: Why provide the actual company report or retrieve current information rather than rely on the model’s recollection?
    Answer

    Providing the report or retrieving information puts relevant evidence in the context, including facts absent from training.

  6. Calculations: Why use executed code to check invoice totals rather than trust a fluent explanation?
    Answer

    Executed code calculates totals using explicit arithmetic. A generated explanation predicts text rather than executing the calculation.

  7. Reinforcement learning: Why is reinforcement learning easier for arithmetic than for writing a good sales email?
    Answer

    Arithmetic has answers that code can check and reward automatically. A good sales email depends on human judgment, so defining the reward is harder.

2. Text representation

Bits and bytes

  1. Copy the first sentence from fineweb_corpus.txt.
  2. Open CyberChef’s binary converter (free). Paste the sentence into Input. Each eight-digit group in Output represents one byte. Save the output as fineweb_bits.txt using the output’s Save icon.
  3. Open the decimal byte converter. Paste the same sentence into Input. Save the output as fineweb_bytes.txt.

Tokenization

  1. Paste fineweb_corpus.txt into Tiktokenizer. Keep the default GPT-4o selection.
  2. Copy the token IDs and save them as fineweb_tokens.txt.

  3. Enter a prompt and click Generate.
